# Mac → VMware → Kubernetes → GitOps interactive guide

The interactive companion to [`../LAB-GUIDE.md`](../LAB-GUIDE.md).

```bash
npm install
npm run dev
npm test
```

The site uses vinext and OpenAI Sites. The published artifact is ordinary
HTML/CSS/JavaScript, while the source uses React for the flow switcher, code
tabs, terminal animation, scroll navigation, and persisted failure-drill checks.
